Email signature

Pick a version, press Copy, then paste into Gmail: Settings, See all settings, General, Signature. The image stays sharp on retina and links to your link page. The text line under it is tappable and still shows when an email app blocks images.

How to install in Gmail

  1. Press Copy signature on the version you want.
  2. Open Gmail settings, General, scroll to Signature, create one called Ryan.
  3. Click in the box and paste (Cmd+V). Don't resize the image.
  4. Under Signature defaults, set it for new emails and replies (for ryan@ryanrosenthal.com). Save at the bottom.
